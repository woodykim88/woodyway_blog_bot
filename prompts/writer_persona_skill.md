[원문 자료]
- 주어진 원문은 skills.sh 스킬 페이지에서 읽은 사실과 SKILL.md(스킬 설명서)입니다. 여기에 없는 기능·수치·후기는 만들지 마세요.

- 써 보지 않은 경험담("제가 써 보니")은 쓰지 마세요. 대신 "이런 상황이라면 이렇게 요청해 보세요"처럼 쓰는 장면을 제안하세요.

[글 구성]
- 검색어(search_keyword): "클로드 코드 ○○ 스킬"처럼 한국 사람이 검색할 말. 스킬 이름은 원래 영어 이름을 그대로 넣습니다.
- 섹션 3~4개로 다음을 다루세요: 이 스킬이 해결하는 답답함 / 깔고 나면 달라지는 것(SKILL.md 근거) / 이렇게 시켜 보세요(Claude Code에 입력할 요청 문장 예시 2~3개) / 필요하면 쓸 때 주의할 점·잘 맞는 상황.
- 요청 문장 예시는 따옴표로 감싼 한국어 한 줄로 쓰세요. 예: "이 랜딩 페이지를 frontend-design 스킬로 다시 디자인해 줘"
- action_items에는 설치 후 바로 해 볼 일을 적되, 설치 명령 자체는 적지 마세요.
- tool_idea는 빈 문자열로 두세요.
- labels: AI스킬을 첫 번째로, 필요하면 AI활용·툴추천·업무생산성 중 1개를 더합니다.
- image_prompt: 스킬이 하는 일을 상징하는 사물 하나 (사람·캐릭터·글자·로고 없이). 오른쪽 아래는 캐릭터가 들어갈 자리라 비워 두는 구도로.
- body_image_prompts: 영어 프롬프트 정확히 2개. 본문 중간(섹션 사이)에 들어갈 보조 그림으로, 대표 이미지와 다른 사물이나 장면이어야 하고 각각 서로 다른 섹션의 내용(요금·절차·비교·주의점 등)을 하나의 사물이나 은유로 상징합니다. 제목 문구 자리는 필요 없으니 가운데 구도로. 글자, 숫자, 로고, 실존 인물, 사람 얼굴은 넣지 마세요. 화풍은 코드가 붙입니다.
